## はじめに

生成AI初心者の私が、先日「Claude Code」を初めて使ってみました。正直なところ、コマンド操作は難しいイメージがあったのですが、いざ触ってみると、驚くほど直感的で使いやすかったです。
本記事では、AIツールにあまり馴染みがない方でも「これならできそう」と感じてもらえるよう、インストールから基本の操作まで、私の実体験をベースに解説していきます。

## Claude Codeとは

Anthropic社が提供する「エージェント型AIコーディングツール」です。
自然言語での指示をもとに、ソースコードの編集、テストの実行、デバッグ、Git操作などの複雑なエンジニアリングタスクを自律的に遂行できる点が大きな特徴です。これにより、開発者はIDEとターミナルを行き来することなく、対話形式でシームレスに開発を進めることができます。

## 【準備】Claude Codeのインストールと初期設定

### 前提条件

Node.jsのバージョンがv18以上であることを確認してください。

:::message

Node.jsのバージョンは、ターミナル（Windowsなら、PowerShellやコマンドプロンプト）で、以下のコマンドを入力して確認出来ます。
「node --version」

:::

### インストール方法

ターミナルを開き、以下のコマンドを入力します。

```Bash
npm install -g @anthropic-ai/claude-code
```

### 初期設定

インストールが終わったら、初期設定をします。

1. ターミナルを開き、「claude」のコマンドを入力します。
2. claudeのCLIで、CLIテーマ、Claudeアカウントのサブスクリプション等を設定します。
3. 「Claude Code vX.X.XXX(バージョン)」と表示されたら、セットアップ完了です。

## 【実践】Claude Codeに仕事を任せてみた

例えば、以下のようなファイル構成となっているソースコードについて、
既存ソースコードの解析と概要ドキュメントの生成の2つを実施してみます。

```markdown
**フォルダ構成:**
src/
 └─ data_processor.py
```

```python:data_processor.py
import json
import os

def p(f):
    # ファイルを読み込んで処理する関数だが名前が不適切
    if not os.path.exists(f):
        return None
    
    with open(f, 'r') as file:
        d = json.load(file)
    
    res = []
    for item in d:
        # 'val'キーの値を1.1倍する謎の計算
        if 'val' in item and item['val'] > 0:
            n = item.get('n', 'unknown')
            v = item['val'] * 1.1
            res.append({'name': n, 'score': v})
        else:
            # 負の値やキーがない場合はスキップ
            pass
            
    # スコア順にソート
    res.sort(key=lambda x: x['score'], reverse=True)
    
    # 上位3つだけ返す
    return res[:3]

print(p('data.json'))
```

````markdown:data_processor.md
## 関数: p(f)

### 概要

JSONファイルを読み込み、各要素の `val` フィールドを1.1倍したスコアを計算して、スコア上位3件をリストで返す。

### シグネチャ

```python
def p(f: str) -> list[dict] | None
```

### 引数

| 引数名 | 型 | 説明 |
| --- | --- | --- |
| `f` | `str` | 読み込むJSONファイルのパス |

### 戻り値

| 条件 | 戻り値の型 | 内容 |
| --- | --- | --- |
| 正常処理 | `list[dict]` | スコア降順で最大3件の辞書リスト |
| ファイルが存在しない | `None` | — |

正常処理時の各要素の構造

```python
{
    "name": str,   # 入力の 'n' キーの値。存在しない場合は 'unknown'
    "score": float # 入力の 'val' を 1.1 倍した値
}
```

### 入力JSONの期待フォーマット

```json
[
  {"n": "Alice", "val": 85},
  {"n": "Bob",   "val": 90},
  {"n": "Carol", "val": 70},
  {"n": "Dave",  "val": -5}
]
```

- トップレベルはリスト形式であること
- 各要素はオブジェクト（辞書）形式であること
- `val` キーが存在し、正の数値である要素のみ処理対象となる
- `n` キーは省略可能（省略時は `"unknown"` として扱われる）

### 処理フロー

```plaintext
ファイル存在確認
  └─ 存在しない → None を返す
  └─ 存在する   → JSON を読み込む
                    ↓
                各要素をループ
                  └─ 'val' キーなし or val <= 0 → スキップ
                  └─ 条件を満たす → score = val * 1.1 で結果リストに追加
                    ↓
                score の降順にソート
                    ↓
                上位3件を返す
```

### 使用例

```python
# data.json の内容:
# [{"n": "Alice", "val": 85}, {"n": "Bob", "val": 90}, {"n": "Carol", "val": 70}]

result = p('data.json')
# => [
#      {'name': 'Bob',   'score': 99.0},
#      {'name': 'Alice', 'score': 93.5},
#      {'name': 'Carol', 'score': 77.0}
#    ]
```

### 注意事項

- ファイルが存在するがJSON形式が不正な場合、`json.JSONDecodeError` が発生する（現在はハンドリングなし）
- 入力リストの要素数が3件未満の場合、存在する件数のみ返す
- `val` が `0` の要素は処理対象外となる（`val > 0` が条件）

````

## 【応用】サブエージェントでタスクを分身させる方法

ここからがClaude Codeの真骨頂です。  
1つの大きなタスクを依頼した際、Claude Codeは必要に応じて **「サブエージェント」という分身** を生成します。
例えば、「アプリ全体のドキュメントを作って」と頼むと、メインのエージェントが構成を考え、サブエージェントたちが各ファイルの解説を並列で書き上げるといった協力プレイが始まります。

### サブエージェントの作成

サブエージェントは以下の手順で作成します。

1. ターミナルを開き、「claude」のコマンドを入力します。
2. claudeのCLIで「/agents」と入力します。
3. agentの作成で、保存先のフォルダ、サブエージェントの役割等を設定します。
4. 作成が完了すると、3.で指定したフォルダ内にサブエージェントが生成されます。サブエージェントのプロンプトが自動生成されているので、必要に応じて中身を書き換えます。

### サブエージェントの呼び出し方法

claudeのCLIで実行する際に、サブエージェントのキーワードが指示に含まれていると、その内容から推測してサブエージェントが呼び出されます。  
例えば、ソースコードのリファクタリングを行うサブエージェントを作成した状態で以下のように実行します。

```markdown
**入力プロンプト:**
> data_processor.pyのソースコードの可読性を高めてください。
```

すると、リファクタリングが行われて、先ほどのソースコードが以下のように修正されます。

```python:data_processor.py
import json
import os


def process_file(filepath: str) -> list[dict] | None:
    if not os.path.exists(filepath):
        return None

    with open(filepath, 'r') as file:
        data = json.load(file)

    results = []
    for item in data:
        if 'val' in item and item['val'] > 0:
            name = item.get('n', 'unknown')
            score = item['val'] * 1.1
            results.append({'name': name, 'score': score})

    results.sort(key=lambda x: x['score'], reverse=True)
    return results[:3]


if __name__ == '__main__':
    print(process_file('data.json'))

```

## 実際に使ってみて分かった「よかった点」と「注意点」

### よかった点

- 圧倒的なコンテキスト理解
  - 「xxのフォルダ内のファイルと同じように出力して」というように、多少指示が曖昧でも指示した通りにファイル出力してくれます。
  - 「この箇所だけ修正して」というように指示すると、指示した部分だけ修正してくれます。
- 作業の断絶がない
  - エディタとターミナルを行き来する回数が激減し、集中力が維持されます。

### 注意点

- APIコスト
  - 大規模なプロジェクトで全ファイルを読み込ませると、APIのトークン消費が早くなります。
- Claude Codeの実行による書き換えに注意
  - Claude Codeは便利な反面、意図しない修正が入ることもあります。
  - Gitで変更履歴の差分を確認できる状態で、Claude Codeを実行しましょう。

## まとめ

- Claude Codeは、単なるチャットツールではなく、ターミナルの中に住む優秀なジュニアエンジニアのような存在です。
- ソースコード解析やドキュメント生成などが簡単に出来ます。
- 便利な反面、ソースコードやドキュメントの意図しない修正には注意が必要です。
