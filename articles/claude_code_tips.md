## はじめに

生成AI初心者の私が、先日「Claude Code」を初めて使ってみました。正直なところ、コマンド操作は難しいイメージがあったのですが、いざ触ってみると、驚くほど直感的で使いやすかったです。
本記事では、AIツールにあまり馴染みがない方でも「これならできそう」と感じてもらえるよう、インストールから基本の操作まで、私の実体験をベースに解説していきます。

## Claude Codeとは

Anthropic社が提供する「エージェント型AIコーディングツール」です。
自然言語での指示をもとに、コードの編集、テストの実行、デバッグ、Git操作などの複雑なエンジニアリングタスクを自律的に遂行できる点が大きな特徴です。これにより、開発者はIDEとターミナルを行き来することなく、対話形式でシームレスに開発を進めることができます。

## 【準備】Claude Codeのインストールと初期設定

### 前提条件

Node.jsのバージョンがv18以上であることを確認してください。

:::message

Node.jsのバージョンは以下のコマンドで確認することが出来ます。
「node --version」(Windowsの場合)

:::

### インストール方法

ターミナルを開き、以下のコマンドを入力します。

```Bash
npm install -g @anthropic-ai/claude-code
```

### 初期設定

インストールが終わったら、初期設定をします。

1. ターミナルを開き、以下のコマンドを入力します。

    ```Bash
    claude
    ```

2. ターミナルで以下の設定をします。
    1. CLIテーマの設定
    2. ログイン方法の設定（本記事では「Claude AI」を使用）
        - 「1. Claude account with subscription」を選択します。
        - Web画面の指示に従って、APIを使うための設定をします。
    3. ターミナルの設定
    4. ワークスペースフォルダの閲覧モードを設定

3. 「Claude Code」と表示されたら、セットアップ完了です。

## 実際に使ってみて分かった「よかった点」と「注意点」

### よかった点

- 圧倒的なコンテキスト理解
  - 「xxのフォルダ内のファイルと同じように出力して」というように多少指示が曖昧でも、指示した通りにファイル出力してくれます。
  - 「この箇所だけ修正して」というように指示すると、指示した部分だけ修正してくれます。
- 作業の断絶がない
  - エディタとターミナルを行き来する回数が激減し、集中力が維持されます。

### 注意点

- APIコスト
  - 大規模なプロジェクトで全ファイルを読み込ませると、APIのトークン消費が早くなります。
- Claude Codeの実行による書き換えに注意
  - Claude Codeは便利な反面、意図しない修正が入ることもあります。
  - Gitで変更履歴の差分を確認できる状態で、Claude Codeを実行しましょう。

## まとめ

- Claude Codeは、単なるチャットツールではなく、ターミナルの中に住む優秀なジュニアエンジニアのような存在です。
- コード解析やドキュメント生成などが簡単に出来ます。
- 便利な反面、コードやドキュメントの意図しない修正には注意が必要です。
